# Applesoft BASIC コマンドリファレンス

Apple II Plus に搭載された Applesoft BASIC のコマンド一覧です。
このエミュレータで実行可能な主要コマンドを記載しています。

------------------------------------------------------------
## 1. 画面制御

### HOME
```
構文: HOME
説明: 画面をクリアして、カーソルを左上に移動する
例: HOME
```

### CLEAR
```
構文: CLEAR
説明: メモリをクリアして変数をリセット
例: CLEAR
```

### PRINT（または ?）
```
構文: PRINT 式1, 式2, ... または PRINT "文字列"
説明: テキストを画面に出力（複数の式をカンマで区切ると列揃えされる）
例: PRINT "HELLO WORLD"
例: PRINT "X="; X; "Y="; Y
例: ? 10 + 20
```

### PRINT TAB
```
構文: PRINT TAB(n) "文字列"
説明: n列目から文字列を出力
例: PRINT TAB(10) "RIGHT"
```

### INPUT
```
構文: INPUT 変数名 または INPUT "メッセージ"; 変数名
説明: キーボードからユーザー入力を受け付ける
例: INPUT X
例: INPUT "Enter your age:"; AGE
```

------------------------------------------------------------
## 2. 変数と配列

### LET（または直接代入）
```
構文: LET 変数名 = 式 または 変数名 = 式
説明: 変数に値を代入
例: LET X = 10
例: Y = X + 5
```

### DIM
```
構文: DIM 配列名(サイズ), 配列名2(サイズ)
説明: 配列を宣言してメモリを確保
例: DIM A(100)
例: DIM X(50), Y(50)
```

------------------------------------------------------------
## 3. 制御フロー

### IF-THEN
```
構文: IF 条件 THEN ステートメント または IF 条件 THEN 行番号
説明: 条件が真なら、後続のステートメントを実行
例: IF X > 10 THEN PRINT "BIG"
例: IF X = 0 THEN 100
```

### IF-THEN-ELSE（Applesoft の拡張）
```
構文: IF 条件 THEN ステートメント : ELSE ステートメント
説明: 条件分岐（真の場合と偽の場合の処理）
例: IF X > 0 THEN PRINT "POSITIVE" : ELSE PRINT "NOT POSITIVE"
```

### FOR-NEXT
```
構文: FOR 変数 = 初期値 TO 終了値 [STEP ステップ]
      ...
      NEXT 変数
説明: ループ処理。変数を初期値から終了値まで変化させながら繰り返す
例: FOR I = 1 TO 10
      PRINT I
    NEXT I
例: FOR J = 10 TO 1 STEP -1
      PRINT J
    NEXT J
```

### GOTO
```
構文: GOTO 行番号
説明: 指定された行番号へジャンプ
例: GOTO 100
```

### GOSUB-RETURN
```
構文: GOSUB 行番号
      ...
      RETURN
説明: サブルーチンを呼び出して、RETURN で戻る
例: 100 GOSUB 500
    200 END
    500 PRINT "SUBROUTINE"
    510 RETURN
```

### END
```
構文: END
説明: プログラムを終了
例: END
```

## 4. 数値計算と関数

### 基本演算子
```
+ : 加算
- : 減算
* : 乗算
/ : 除算
^ : べき乗
MOD : 余り
```

### ABS
```
構文: ABS(式)
説明: 絶対値を返す
例: X = ABS(-10)  → X = 10
```

### INT
```
構文: INT(式)
説明: 整数部分を返す
例: X = INT(3.7)  → X = 3
```

### SQR
```
構文: SQR(式)
説明: 平方根を返す
例: X = SQR(16)  → X = 4
```

### RND
```
構文: RND(式) または RND
説明: 乱数を返す（0 ～ 1 の間）
例: X = RND(1)
```

### SIN, COS, TAN
```
構文: SIN(角度), COS(角度), TAN(角度)
説明: 三角関数（ラジアン単位）
例: X = SIN(0)  → X = 0
```

### LOG, EXP
```
構文: LOG(式), EXP(式)
説明: 自然対数、指数関数
例: X = LOG(10)
例: Y = EXP(1)
```

------------------------------------------------------------
## 5. 文字列処理

### LEN
```
構文: LEN(文字列)
説明: 文字列の長さを返す
例: X = LEN("HELLO")  → X = 5
```

### MID$
```
構文: MID$(文字列, 開始位置, 長さ)
説明: 文字列の一部を抽出
例: X$ = MID$("HELLO", 2, 3)  → X$ = "ELL"
```

### LEFT$
```
構文: LEFT$(文字列, 長さ)
説明: 文字列の左から指定文字数を抽出
例: X$ = LEFT$("HELLO", 3)  → X$ = "HEL"
```

### RIGHT$
```
構文: RIGHT$(文字列, 長さ)
説明: 文字列の右から指定文字数を抽出
例: X$ = RIGHT$("HELLO", 2)  → X$ = "LO"
```

### STR$
```
構文: STR$(数値)
説明: 数値を文字列に変換
例: X$ = STR$(123)  → X$ = "123"
```

### VAL
```
構文: VAL(文字列)
説明: 文字列を数値に変換
例: X = VAL("123")  → X = 123
```

### CHR$
```
構文: CHR$(ASCII コード)
説明: ASCII コードに対応する文字を返す
例: X$ = CHR$(65)  → X$ = "A"
```

### ASC
```
構文: ASC(文字列)
説明: 文字列の最初の文字の ASCII コードを返す
例: X = ASC("A")  → X = 65
```

------------------------------------------------------------
## 6. メモリアクセス

### PEEK
```
構文: PEEK(アドレス)
説明: 指定メモリアドレスの値を読み込む
例: X = PEEK(1024)  → テキスト画面の先頭を読む
例: X = PEEK(49152)  → グラフィックスメモリを読む
```

### POKE
```
構文: POKE アドレス, 値
説明: 指定メモリアドレスに値を書き込む
例: POKE 1024, 65  → テキスト画面に "A" を描画
```

### CALL
```
構文: CALL アドレス
説明: 指定メモリアドレスのマシンコードを実行
例: CALL 768
```

------------------------------------------------------------
## 7. I/O と キーボード

### GET
```
構文: GET 変数
説明: キーボードから 1 文字入力し、そのASCIIコードを取得
例: GET K
    IF K = 65 THEN PRINT "YOU PRESSED A"
```

------------------------------------------------------------
## 8. グラフィックス（テキストモード向け）

### HTAB / VTAB
```
構文: HTAB 列番号
      VTAB 行番号
説明: カーソルを指定位置に移動（テキストモード）
例: HTAB 10
    VTAB 5
    PRINT "HERE"
```

### COLOR
```
構文: COLOR = 色番号
説明: テキスト色を設定（グラフィックスモード向け）
例: COLOR = 1
```

### PLOT
```
構文: PLOT 列, 行
説明: グラフィックスモードで点を描画
例: PLOT 100, 50
```

### HLIN / VLIN
```
構文: HLIN 列1, 列2 AT 行
      VLIN 行1, 行2 AT 列
説明: グラフィックスモードで水平線 / 垂直線を描画
例: HLIN 0, 39 AT 10
例: VLIN 0, 20 AT 15
```

------------------------------------------------------------
## 9. その他のコマンド

### REM
```
構文: REM コメント または ' コメント
説明: コメント行（実行されない）
例: REM THIS IS A COMMENT
例: ' This is also a comment
```

### RANDOMIZE
```
構文: RANDOMIZE
説明: 乱数シードを初期化
例: RANDOMIZE
```

### SPEED
```
構文: SPEED = 値
説明: 画面表示速度を設定（0 ～ 255）
例: SPEED = 100
```

------------------------------------------------------------
## 10. 比較演算子と論理演算子

### 比較演算子
```
=   : 等しい
<   : 小さい
>   : 大きい
<=  : 以下
>=  : 以上
<>  : 異なる
```

### 論理演算子
```
AND : 論理積
OR  : 論理和
NOT : 否定
```

例：
```
IF X > 5 AND Y < 10 THEN PRINT "OK"
IF X = 0 OR X = 10 THEN PRINT "BOUNDARY"
IF NOT (X = 0) THEN PRINT "NOT ZERO"
```

------------------------------------------------------------
## 11. 注意点

### メモリアドレス
- $0400-$07FF：テキスト画面バッファ
- $C000：キーボード入力
- $C030：スピーカークリック

### 浮動小数点演算
Applesoft BASIC は浮動小数点を完全サポートしていますが、
Integer BASIC（初代 Apple II）では整数のみです。
